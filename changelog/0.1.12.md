## added
- [effect] `effect.json` keys `knobs`, `levels`, `levelHeights`; `unit.json` key `knobs`; skill `quality.md`
- [effect] knob: `kind` `continuous` | `discrete`, `moves` `frame` | `boundary`, optional `rests` `shader` | `asset` | `feature`; `lodBias` per level
- [render] alternative `set`: element `off` (no draw, shadow draw, compute dispatch for that instance), other `material`, `mesh`, material `variants`; one draw per alternative in use
- [shaders] `FxKnob(FxInstance, uint)`, generated `FX_KNOB_<ID>` in `units.slang`
- [fxapi] ABI 5 (3, 4 still load): `Ctx::knob`, `Ctx::level`, hook `Effect::level(ctx, it, from, to)`
- [level] choice: level name, `screen` (per instance by screen height), `load` (GPU budget in ms, smallest instances lowered first, `boundary` knobs only at a boundary)
- [scenario] `level` at top and per entry; order `level` with arg `name`; entry `copies` `{count, spread}`
- [cli] `--level <name|screen|load:ms>` on `play`, `end`, `measure`, `influences`; request key `level` in `shot`
- [play] `--profile --level all`: table per level, summary level x GPU ms, draws, shadow draws, triangles, compute ms
- [compare] `level` per side; `load` refused
- [levels] command `fxengine levels <effect>`: `out/levels/<effect>/levels.json`, `index.html`; picture, cost, residency, difference from first level per level, view, time
- [editor] panel «Качество» per viewport: level picker, knobs, «вручную»; flags `--switch level:<l>@s`, `--switch knob:<id>=<v>@s`
- [editor] «Таблица элементов»: level of each instance, knob column, instance count per level
- [check] load and `passport` errors on bad knobs and levels; warning on a level costlier than the one above it (`levels`)
- [passport] `quality` block: knob ids, texts, `moves`, `rests`, levels; `project.json` key `levels` (recommended count, warning when it differs)
