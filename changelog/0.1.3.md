- [effect] material `shaderPath`, `floats`, `colors`, `vectors`, `keywords`, `queue` -> `program`, `values`, `variants`, `phase`, `order`; migrate: declare `programs[]` in `effect.json`/`unit.json`, point materials at them
- [effect] texture key `st` -> `transform`; texture sidecar key `source` dropped
- [effect] shaders read from `Assets/VFXing/<id>/` -> from the effect folder (`shaders/*.slang`, `units/<u>/*.slang`); migrate: move shader files into the effect
- [effect] generated `UnitMemory.hlsl`, `FX_MEM_<UNIT>`, `FX_MEM_SIZE`, `FX_UNIT_MEMORY` -> generated `shaders/units.slang`, `MEMORY_<UNIT>`, `MEMORY_<UNIT>_SIZE`, `MEMORY_SIZE`
- [effect] `computes[].shader` -> `computes[].file`; `FX_KERNEL(Name)` -> `[shader("compute")] [numthreads(FX_KERNEL_THREADS,1,1)]` + `FxKernelItemAt`
- [effect] `_FxMesh`/`FxMeshVariant()` -> `FxLoadMeshVertex`/`FxMeshIndex()`; `_FxShadingRate` -> pass `shadingRate`
- [cli] `fxengine import <Effect.asset>` removed; `workspace --unity <dir>` removed; `workspace.json` `unity` key ignored; `fxengine workspace` output drops `unity`, `unity_found`
- [stand] schema in engine terms; 0.1.2 keys not read: `maxAdditionalLights` -> `maxPointLights`, `additionalShadows` -> `pointShadows`, `additionalShadowRes` -> `pointShadowAtlas`, `additionalShadowTiers` -> `pointShadowTiers`, `anisotropic` -> `forceAnisotropy` (bool), sun `usePipelineBias` -> `sharedBias`, fog mode `Linear|Exponential|ExponentialSquared` -> `linear|exp|exp2`, `castShadows` `On|TwoSided|ShadowsOnly|Off` -> `on|only|off`; `renderingMode`, `opaqueDownsampling`, terrain detail `renderMode` dropped

- [stand] stand `unity/Assets/...` shader copies no longer used
- [fxapi] `Sight.unit: Option<String>` -> `Sight.units: Vec<String>`
## added
- [program] programs as data: `programs[]` with `name`, `file`, `parameters`, `variants`, `passes` (`kind` color|shadow|screen|bake, `phase`, `order`, blend/depth/cull/stencil state); engine programs `lit`, `character`, `terrain`, `sky`, `topblend`, `tree`, `leaf`, `screen-generic`, `screen-haze`, `taa`
- [shaders] Slang library `shaders/fx/`: math, random, noise, color, distance, volume, uv, frame, instance, geometry, scene, light, surface, air, decal, screen, compute, terrain
- [shaders] `FxBlueNoise`: spatiotemporal blue noise 128x128x64 (`shaders/data/blue-noise.r8`), bound as `fxBlueNoise` to draws, kernels, bakes
- [shaders] `fxFrameColor` (frame copy before screen passes); scene colour with full mip chain for `FxSceneColorBlurred`
- [shaders] `FxSampleTerrainSurface`, `FxTerrainHeight`: stand terrain bound to every draw and kernel
- [shaders] light library: `FxSunLight`, `FxLightSurfaceDirect`, `FxLightVolumeDirect`, `FxFogColor`; lights reach transparent passes
- [shaders] `FxLoadInstanceAtSlot`; `FxLoadInstance` in a kernel returns the kernel's own instance
- [compute] kernels see camera and stand opaque depth: `FxSceneViewDepth`, `FxSceneNormalWorld`, `FxCollideWithScene`
- [render] TAA: Halton 2,3 jitter over 8 frames, depth-motion resolve with clipped history; `FxFrameIndex()`; `FxDitherDiscard` on STBN; editor always on, `play --taa`, shot `"taa": true`
- [mesh] LOD: coarser levels `<name>_LOD1`, `_LOD2`, ... from the same `.glb`, chosen per instance by screen height (default level k while height >= 0.25/2^k), shadows follow camera choice; element `lod: false | {heights, meshes}`
- [mesh] element without `copies`: mesh as vertex inputs by semantic (`POSITION`, `COLOR0`, `TEXCOORD1`), missing streams constant; `FxMeshVertex` carries `COLOR_0` and `TEXCOORD_1`
- [effect] element `topology` optional, `"Triangles"` only, default
- [cli] `fxengine compile <program> [pass] [VARIANT=value...]`
- [cli] `fxengine shaders <effect> [--base n|main] [--unit u[,u]]`: compiles every pass the effect would draw, no device
- [cli] `fxengine workspace init <dir>`
- [cli] `fxengine effect export <id> [--out file.zip]`, `effect import <file.zip> [--as id]`: carry effect + all main-line snapshots between workspaces; `--as` rewrites the id
- [cli] effect groups (`groups/<g>.json`): `effect copy <id> <new> [--group g [--of id --kind k]]`, `effect variant <id> <new> [--kind k]` (default `optimized`), `group list|show|new|add|move|copy|remove`; `fxengine workspace` output gains `groups`
- [cli] `--unit u,v` / request `unit: ["u","v"]`: drafts of several units at once (`end`, `measure`, `shaders`, shot, compare)
- [cli] `play --taa`
- [bake] spec runs a program `.json` (`program`, `pass`, `values`, `textures`, `variants`) into up to 4 RGBA32F targets
- [editor] up to 4 viewports, each with own stand, effect, camera, time, versions, profiler; «Вместе» linked time; `--focus i@s`
- [editor] left/bottom/right panels hideable, kept in `out/editor.json`
- [editor] effect menus grouped by group: sources, variants `(kind)`, then «без группы»
