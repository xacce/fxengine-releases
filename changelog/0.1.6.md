## added
- [view] `fxengine view <request.json> [--workspace dir] [--validate]`: mesh assets on a stand, every view x every show in one launch -> `<out_dir>/<view>_<show>.png` + `view.json`
- [view] request `objects[]`: `mesh` `file.glb` (whole default scene, node transforms) or `file.glb#Name`; `at`, `rotate` (deg, Y X Z), `scale`; `surface` role -> `file` or `file:channel`; `tile {size, repeat_m}`
- [view] roles `color alpha normal roughness metallic occlusion emission`; fallback `surface` -> glb material map + factors -> constant; `COLOR_0` multiplies base colour
- [view] `views[] {name, pos, target}` in the stand anchor frame; `around {count, distance, height}`
- [view] `show[]`, default `["lit"]`: `lit`, `wire`, `checker`, `<stream>[.<ch>]` (`color0 texcoord0 texcoord1 normal tangent`, raw), `<role>[.<ch>]` (map as sampled)
- [view] `view.json`: pictures; per object bounds, triangles, vertices, streams, materials, maps (size, channels, uses), per-mesh parts; `ms {load, render, total}`
- [view] exit 1 with the file named: glb missing/unreadable/invalid/cut short, `#Name` absent, stream or channel absent, map missing/unreadable/channel absent, object outside every view
- [shaders] engine program `view` (`shaders/engine/view.slang`)
- [textures] JPEG maps readable (`image` `jpeg` feature)
- [skills] `skills/fxengine/view.md`
